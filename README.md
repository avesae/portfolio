# Портфолио Ивана Сандыги

Личный сайт-портфолио: кто я, что предлагаю, проекты и контакты. Есть русская и английская версии.

- 3D-заставка «ночная дорога» на [Three.js](https://threejs.org/)
- Статический сайт без сборки: `index.html`, шрифты и Three.js лежат рядом
- Внешних запросов нет: шрифты и библиотека подключены локально

## Как запустить

Открой `index.html` в браузере или выложи папку целиком на любой статический хостинг (Netlify, Vercel, GitHub Pages).
